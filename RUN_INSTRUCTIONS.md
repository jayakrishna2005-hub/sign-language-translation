# 🚀 Simple Steps to Run the Project

1. **Open Terminal** and run:
   ```bash
   cd "/Users/jayakrishna/Desktop/MINOR PORJECT/sign language"
   ```

2. **Activate Virtual Environment**:
   ```bash
   source venv/bin/activate
   ```

3. **Start the Application**:
   ```bash
   python apps.py
   ```

4. **Open in Browser**:
   - [http://127.0.0.1:8000](http://127.0.0.1:8000)
   - [http://127.0.0.1:8000/scan_gesture](http://127.0.0.1:8000/scan_gesture)

---

### Tips for Scanning:
- Sign letters (`A-Z`) to spell out words.
- Rest/drop your hand for ~1 sec or press the **Spacebar** to commit the word.
- Choose your preferred Indian translation language from the dropdown.
- Click **Listen** to hear audio output.
